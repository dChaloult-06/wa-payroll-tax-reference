## How to Publish on GitHub Pages

Follow these steps exactly. No coding required after setup.

### Step 1 — Create a GitHub Account
If you don't already have one:
1. Go to [github.com](https://github.com)
2. Click **Sign up**
3. Choose a username (e.g., `dorothy-chaloult` or `payrolltaxref`)
4. Complete email verification

---

### Step 2 — Create a New Repository
1. Once logged in, click the **+** icon in the top right → **New repository**
2. Name it: `wa-payroll-tax-reference`
   - This will become part of your URL, e.g.: `yourusername.github.io/wa-payroll-tax-reference`
3. Set visibility to **Public** (required for free GitHub Pages)
4. Check **"Add a README file"**
5. **Leave the license dropdown blank — do not select one**
6. Click **Create repository**

---

### Step 3 — Upload Your index.html File
1. In your new repository, click **Add file** → **Upload files**
2. Drag and drop the `index.html` file from this folder
3. Scroll down and click **Commit changes**

---

### Step 4 — Enable GitHub Pages
1. In your repository, click **Settings** (top menu)
2. In the left sidebar, click **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Under **Branch**, select **main** and folder **/ (root)**
5. Click **Save**
6. Wait 1–2 minutes, then refresh the page
7. You will see a green banner: **"Your site is live at https://yourusername.github.io/wa-payroll-tax-reference"**

---

### Step 5 — Access Your Live Site
Your tool will be publicly accessible at:
```
https://yourusername.github.io/wa-payroll-tax-reference
```

Share this link anywhere — LinkedIn post, email, resume. Anyone with a browser can access it. No login required.

---

## How to Update Content (When Rates Change)

1. Go to your repository on github.com
2. Click on `index.html`
3. Click the **pencil icon** (Edit this file)
4. Make your changes
5. Click **Commit changes**
6. Your live site updates automatically within 1–2 minutes

## Optional: Custom Domain

To use a custom URL like `payrolltaxref.com`:

1. Purchase a domain from Namecheap, Google Domains, or similar (~$12/year)
2. In GitHub Pages Settings, enter your custom domain
3. Update your domain's DNS settings per GitHub's instructions
4. GitHub provides free HTTPS automatically
