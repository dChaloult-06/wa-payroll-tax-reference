## What’s Covered

This reference tool includes:

- **Tax rates** for all 2026 Washington State payroll obligations
- **Statutory citations** linking directly to the Revised Code of Washington (RCW)
- **Agency guidance** from L&I, ESD, and other state agencies
- **Nexus rules** for remote and out-of-state employers
- **Direct links to official sources** — no secondhand summaries
